## LinkedIn post

```
Claude Memory 2.0 has one setting that decides whether any of it works.

Anthropic merged Claude Chat and Cowork into a single memory. It organises
what it knows into three pillars you can open and read: Work Context,
Personal Context, Top of Mind.

You edit it by talking to it. I told it to structure every YouTube outline
in 3 bullets with exact timecodes. It re-indexed in under 3 seconds, and a
blank chat obeyed with no reminder and no pasted context.

Then the part nobody mentions.

The bridge only works if Cowork runs in the cloud. Run it in the desktop app
and the session is sandboxed on your machine — nothing reaches your chat
history and nothing compounds. One toggle, and half of this update quietly
does nothing.

Sensitive topics are blocked by default too: health, beliefs, private
details. Turning that off is a decision you make on purpose, not a default
you inherit.

The shift is not that Claude remembers. It is that the memory is a file you
can argue with, instead of a 50-page history you delete to fix one line.
```
