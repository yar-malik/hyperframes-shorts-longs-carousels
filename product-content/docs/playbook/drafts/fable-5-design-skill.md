# Fable 5 + the design skill — all four cuts

Source: **"Claude Fable 5 + New Design Skill = Beautiful $10,000 Websites"**
— Published on the board, 8 min, scored 7. Every specific is from that
transcript.

The angle is the video's own reversal: everyone is crediting the skill, and
the skill is a markdown file. It is the model doing the work. That contrarian
read is the post — it is the one thing the other twenty posts about this are
not saying.

---

## LinkedIn post

```
Everyone is crediting the design skill. I opened one. It is a markdown file.

The claim going round is that a free design skill plus Claude Opus builds a
website an agency would charge $10,000 for. The claim is roughly true. The
explanation is wrong.

A skill has no code in it. It is instructions in a folder that the agent
reads before it starts. Open the good ones and there are three ideas:

1. It interviews you before it builds anything
2. It splits the work, so the expensive model is only used where judgment
   shows
3. It argues with the plan before there is anything to argue about

None of that is taste. It is process. The taste — the layout decisions, the
scroll logic, tying it into one coherent thing — is Opus, and it would be
Opus with or without the file.

Which matters, because it changes what you do next. If the skill were the
magic you would go collecting skills. It isn't, so you write better
instructions for the model you already pay for. That is a much shorter
afternoon.

One thing the skill genuinely cannot do: generate the visual material. Opus
is strong at structure and weak at inventing imagery, so the raw visuals come
from elsewhere and the model builds around what already exists.
```

*1,187 characters. Long, and earning it — the whole post is one argument and
the numbered list is the evidence.*
