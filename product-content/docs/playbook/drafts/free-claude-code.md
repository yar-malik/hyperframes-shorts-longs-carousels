# Free Claude Code (FCC) — all four cuts

Source: **"Free Claude Code (FCC): So, this SIMPLE Tool makes Claude Code
FREE — OFFICIALLY!?"** — Published on the board. Every number below is from
that transcript.

The angle: it is a proxy, not a hack. Saying what it actually does is more
convincing than the word "free", and it is the part every other post about
this leaves out.

---

## LinkedIn post

```
A GitHub project with 52,700 stars sits between Claude Code and Anthropic,
and your terminal never notices.

It is called FCC. Your coding agent thinks it is talking to Anthropic like
normal. Behind it, FCC routes that traffic to whichever provider you have
configured — 50 of them, more than 1.3 billion free tokens a month between
them.

What it actually gives you:
1. 10 agents supported, including Claude Code, Codex, Cline and Open Code
2. Automatic failover — when a provider goes down it swaps to your next
   configured model without restarting anything
3. Terminal output tokens cut by up to 90%, which is quota you were burning
   on nothing

Install is one command, then one more to start the proxy and open the admin
UI where the provider keys go.

The honest part: "free" is doing work in that sentence. You are not getting
Anthropic for nothing — you are routing to providers whose free tiers you now
have to manage, and you own the keys, the config and whatever happens when a
tier changes. It replaces a subscription with an ops job. A small one, but
not zero.

Worth it if you are hitting limits weekly. Noise if you are not.
```
